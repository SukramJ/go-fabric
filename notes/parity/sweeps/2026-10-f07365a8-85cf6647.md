# Parity sweep f07365a8 → 85cf6647

The schema snapshot moved from matter.js f07365a8 to 85cf6647 with PR #24;
only the schema side of that bump was propagated then. This sweep goes
through every matter.js commit in the range that touches the device-side
sources — `git -C ../matter.js log f07365a8..85cf6647 -- packages/node/src
packages/protocol/src packages/types/src`, 76 commits — and records what
each means for go-fabric. `docs/matter-parity-contract.md` ("Sweeping a
pin bump") says how the next one is run.

Verdicts:

1. not applicable to a device-side responder, or to a feature the module
   does not have (controller, BLE, Thread, OTA, BDX, camera, codegen);
2. go-fabric already behaves this way — the Go reference says where;
3. go-fabric differed — fixed (commit) or recorded as a finding.

Totals: 51 × 1, 18 × 2, 7 × 3.
