## Items (each a commit; the finding ID in the commit title)

1. **W1-conc-01 (medium)** — session-0 retransmissions use the 500 ms idle
   default (`bridge/ackpump.go:62-78 outboundBaseInterval`,
   `bridge/outbound_reliable.go:124-131`). Resolve the base interval for a
   session-0 exchange from the handshake's own peer parameters
   (PBKDFParamRequest / Sigma1 `initiatorSessionParams`, decoded by
   `sessionparams.DecodeFields`; the per-exchange PASE/CASE provider holds
   the request) and treat the peer as active in the responder role:
   matter.js `UnsecuredSession.ts:30` (`setActiveTimestamp: !isInitiator`),
   `Session.ts:108-121`, `MRP.ts:181` (activeInterval). Parity test on the
   first retransmit delay of a Sigma2 with a peer that states a shorter
   active interval.
2. **W1-wire-01 (medium)** — `transport/message/message.go:286-317
   UnmarshalHeader`: refuse (a) unicast session type with DSIZ=0b10,
   (b) group session type with DSIZ=0b00, (c) group session type without
   the S flag — `MessageCodec.ts:223-232` (`UnexpectedDataError`), chip
   `MessageHeader.cpp:209-212` for (a). Sentinel errors; mirror (a) in
   `MarshalPacket`. Move the seed at `fuzz_message_test.go:37` to the
   rejected set, bind `SessionType` to `DestSize` in `FuzzMarshalPacket`,
   add the three cases to `messagecodec_parity_matterjs_test.go`.
3. **W1-sec-03 remainder (low)** — a NOC without an ICAC gets no AKID
   check against the root's SKID (`secure/mattercert/verify.go`, the
   `else` branch after `:325`; matter.js `Noc.ts:170-184`). The verifier
   holds the root public key only. Add an **additive** constructor
   `NewVerifierFromRCAC(rcac []byte, ts TimeSource)` (parses the root
   certificate, keeps its SKID) and use it at the callers that have the
   RCAC bytes (`cluster/core/operational_credentials.go:1754` pending root,
   `:1967` the fabric's stored root; `node/security.go:272`, `node/client.go:164`,
   `controller/ca/ca.go:339` where the record carries the root cert);
   `NewVerifier` stays and documents that a root-signed NOC's AKID is not
   checked without the root certificate. `client/jcm/vendorid.go:175` keeps
   `NewVerifier`. Parity case: root-signed NOC with a foreign AKID → refused.
4. **W1-conc-02 (low)** — `bridge/outbound_reliable.go:374, :395-398`: a
   failed send must not consume a retry at pump cadence; restore
   `retries` on a send error so the entry follows the backoff schedule
   (`:343-346` intends it). Unit test with a failing sender.
5. **W1-conc-03 (low)** — `transport/mrp/ack.go:157-175 Owe`: an

   `ReliableMessageMgr.cpp:339-342`, matter.js compares `messageId ===
   sentMessageToAck.ackedMessageId`. Drop the "cumulative ACK" wording at
   `:144-149`.
6. **W1-conc-04 (low)** — `transport/btp/session.go:255-261 newSession`

   before `sendAckTimer.start()`, inside the lock.
7. **W1-conc-05 (low)** — `transport/udp/listener.go:221-227 Serve`: a
   read error that is not the listener's own close continues the loop and
   is logged at Warn (`bridge/bridge.go:865-873` logs the exit at Debug —
   raise to Warn); a persistent error class (the socket gone) still exits.
8. **W1-wire-02 (low)** — `tlv/encode.go:315-321 PutUTF8Bounded`:
