## 2 `controller/topology` (#380)

- Package doc after `controller/softwareupdate/doc.go`: "A port of matterjs-server's `NetworkTopologyService` at 0bd06f22" with the source paths, the exported types, what is left out (border-router registry, route-table supplement — `cmd_topology.go:24-31` states the same) and why (ADR 0027 decision 1: the border-router client is OTBR REST, `thread/otbr`; no `_meshcop` browse exists).
- Types: `Topology{CollectedAt time.Time; Nodes []Node; Connections []Connection}`, `Node{ID string; Kind Kind; NetworkType NetworkType; NodeID uint64 (0 for externals); Role Role; Available bool; IsBridge bool; ExtAddress uint64; Rloc16 uint16; ExtPanID uint64; NetworkName, SSID, BSSID string; Addresses []netip.Addr}`, `Connection{Source, Target string; Network NetworkType; Strength Strength; SourceToTarget, TargetToSource *Direction}`, `Direction{Strength Strength; LQI uint8; RSSI *int8}`, enums `Kind` (matter, thread_unknown, wifi_ap), `Role` (leader, router, reed, end_device, sleepy_end_device, unassigned, station, ap), `Strength` (strong, medium, weak, none, unknown) — the names of `model.ts:273-345` so the server's JSON and the UI's `TopologyGraph` map 1:1. Ids as matterjs-server: decimal node id, `unknown_<EXTADDR 16 hex upper>`, `ap_<BSSID hex without colons>`.
- `Build(images []Image, now time.Time) Topology` as a pure function; `Image` is what one node contributes (`NodeID`, `Available`, `IsBridge`, the typed states of endpoint 0: `networkcommissioning.State` + its FeatureMap, `generaldiagnostics.State`, `threadnetworkdiagnostics.State`, `wifinetworkdiagnostics.State`, `Addresses`); `ImageOf(n *client.Node) (Image, bool)` reads them through `n.Endpoint(0).Cluster(id)` + `StateFrom` (nil-safe) and `n.PeerAddress().NodeID`; network type from endpoint 0's FeatureMap (priority Thread > Wi-Fi > Ethernet, `topology-utils.ts:97-107`), `client.Properties.SupportsX` as the fallback when the cluster is not ready (open question of #380, decided here).
- Rules, each with its matterjs-server citation: node build (`NetworkTopologyService.ts:305-373`), `mapThreadRole` (:435-452), Thread pairs — ext-address map, RLOC16 map, unknown externals (`topology-utils.ts:539-562`), `buildThreadEdgePairs` (:843-967, first direction wins, `makePairKey` :816), `mapThreadPair` (:486-501, a pair with only `none` directions is dropped, strongest level, `LEVEL_RANK` :507), externals published only when linked (:377-396); Wi-Fi pseudo-nodes (:397-427), `getWiFiSsid` (:1076-1110), BSSID formatting (:1033-1047); thresholds `getSignalLevelFromLqi` (`topology-utils.ts:39-43,754-760`) and `rssiToStrength` (:517-523); Thread ext address from `NetworkInterfaces` (iface `Type == Thread`, else first; `cmd_topology.go:421-453` and `topology-utils.ts:197-226`).

## 3 Facade gaps (#381)

- (a) `SubscriptionManager.Snapshot() []SubscriptionInfo` (value type: `ID, FabricIndex, PeerNodeID, SessionID, MinIntervalFloor, MaxIntervalCeiling, KeepSubscriptions, AttributePaths, EventPaths, SendInterval`) built from `snapshot()` (`im/subscription/manager.go:846`); `node.SessionInfo.SubscriptionIDs []uint32` filled in `SessionDiagnostics()` (`node/inspect.go:126-142`); `node.Subscriptions()` doc updated (`node/node.go:1013-1017`).
- (b) `BridgedDevice.Scope string` from `endpoint.Endpoint.Scope`; `Topology()`'s `Added` lookup over every partition (`node/lifecycle.go:153-159` reads the default only — the `Aggregator` needs a partition walk; add `Aggregator.Partitions() []string` if no enumeration exists).
- (c) `BridgedDevice.Tags []core.SemanticTag` (from the Descriptor's TagList when enabled, `cluster/core/descriptor.go:217-222`, else nil — the Apple note :223-232 stands) and `BridgedDevice.Labels []contract.Label` (FixedLabel + UserLabel values when served, `device/defaults.go:141-142`).
- (d) `Observers.OnAttributeChanged func(AttributeChange)`, `AttributeChange{Endpoint uint16; Cluster uint32; Change contract.Change}`, fed from the bridge's notifier wiring (`bridge/subscribe.go:1406-1445`) through the node; `queuedOn` entry (`node/observers.go:288`); runs inline on the change goroutine like the other hooks, `ObserveAsync` queues it. No value in the payload (matter.js `$Changed` carries values per behaviour only; the typed `OnChanged` stays the value route).
- Tests: `fabrictest` site cases for each (a controller subscribes → `Snapshot` lists its paths and the session's ids; a device in a named partition shows its scope; a device with `EnableTagList` shows its tags; a controller write reaches `OnAttributeChanged` with endpoint, cluster, attribute ids and `OriginControllerWrite`); matter.js parity where it tests the counterpart (`SessionsBehaviorTest`, `SubscriptionsServer` tests — name them in the register entries as ported or missing).
- Docs: `docs/guides/observability.md` (the new hook), `docs/guides/host-view.md` (Scope, Tags, Labels), CHANGELOG `### Added`; `script/reachability` snapshot and ratchet.
