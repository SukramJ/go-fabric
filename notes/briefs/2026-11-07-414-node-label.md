## Scope (one shape)

1. `cluster/core`: BasicInformation implements `contract.AttributeChangeNotifier` with
   `cluster.AttributeChanges`; `MatterWrite` of NodeLabel/Location fires the change (origin from
   ctx), after the bump and the persistence hook. A new host-side write path with a controller's
   write semantics — validate (`checkLabelWrite`), set, bump, persist, fire with `OriginHostSet`;
   name it so the restore setter (`SetNodeLabel`, no persistence, no report) stays distinct, or
   rename the restore setter to say what it is (`RestoreNodeLabel`) and make `SetNodeLabel` the
   run-time write — the facade decides the name; one shape, documented in both doc comments.
2. `node`: `Node.SetNodeLabel(ctx context.Context, label string) error` on the facade: refuses
   what a controller's write would (max 32 bytes, as `CheckValue` judges; empty allowed as the
   definition allows), works before Start (the served value at start) and after (reported to
   subscribers and persisted), returns the server's error unchanged. `Node` already exposes the
   root (`node/root.go:63`). The persisted label is restored at the next start as today.
3. Parity cases: (a) the host's set is reported to a subscribed controller and persisted
   (`store` read-back); (b) a controller's later write wins and reaches
   `Observers.OnAttributeChanged` with `OriginControllerWrite`; (c) over-long label refused with
   the same status a controller gets; (d) set before Start serves the label at start. Follow
   the existing BasicInformation and observer tests' shape.
