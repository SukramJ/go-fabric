## API breaks (each a commit; the finding ID in the commit title; a migration line each)

1. **W5-api-01** — `node.Node`: add `CloseWindow(ctx)` ("close the open
   window, whoever opened it", matter.js `DeviceCommissioner.ts:315-325`)
   and `OpenOwnWindow(ctx, timeout)` (the configured-credential window,
   `:130`); remove `Node.CommissioningWindow()` and the `node.CommissioningWindow`
   alias — the bridge's window type with its `Set…` wiring is reached only
   through the advanced seam `Node.Bridge()`. Point `node/doc.go:59-65` and
   `advanced-seams.md` at the new methods; `SetCommissioningBlocked` stays.
   Tests on the facade methods (fabrictest: open, close, reopen own).
2. **W5-api-02** — `device`: remove `Options.Reachable` and
   `HostStatement.Reachable` (the probe); `SetReachable` is the one input,
   which emits ReachableChanged and marks the subscription (matter.js
   `BridgedDeviceBasicInformationServer.ts:37, :100-102`). Keep
   `endpoint`'s probe mechanism only if a caller outside `device/` uses it
   (say which); otherwise remove it too. Test: a reachability change
   reaches a subscription.
3. **W5-api-03** — `node.New(ctx, cfg)`: the store open/migrate and the
   group load run under the caller's ctx; the subscription engine and the
   PASE/CASE reapers start in `Start` (so a node that is constructed and
   dropped leaks nothing; ADR 0026 principle 5). Update every caller
   (`node/controllernode`, `fabrictest`, `examples/*`, docs). Test: `New`
   then no `Start` leaves no goroutine (goleak-style count in the test).
4. **W5-api-04** — one callback rule (ADR 0025 principle 8): `Observers`
   keeps its struct and `Observe`; add `ObserveAsync` (queued, one
   goroutine per node, ordered); move `Health.OnSample` and
   `OTAProviderConfig.OnStatusChange` to `Node.OnHealthSample(fn) (unsubscribe func())`
   / `…Async` and `Node.OnOTAProviderStatus(fn)` / `…Async`. Trace whether
   any observer's `error` return is acted on; if none, drop it, else
   document why only these carry one. One sentence in `docs/guides/host-view.md`
   states the rule for every callback.
5. **W5-api-05** — remove `device.Logger` (package global); the logger is
   `Options.Logger` (new field, nil = `slog.Default()` at call time) or the
   node's through `deviceseam.Host`; `defaults_test.go` runs parallel again.
6. **W5-api-08** — `device`: remove `WithServer` (keep `HostServer`), the
   `Option = Declaration` alias, and `TypeByID` (keep `Lookup(uint32)`);
   update `migrating-to-the-facade.md:237`.
7. **W5-api-09** — `node`: remove `PairingCodes()` (keep `SetupPayload`,
   `PairingCodesFor`); one `IncreaseConfigurationVersions(ctx, keys...)`
   returning the `ErrNotStarted` sentinel (remove the singular);
   `Commissioning.PBKDFIterations` and `WindowCredentials.Iterations` both
   `PBKDFIterations uint32`, the clamp at `credentials.go:79-92` gone.
8. **W5-api-10** — one opt-in idiom in `node.Config`: an optional
   sub-system is a pointer (nil = off): `Client *ClientConfig` replaces
   `Client.Enabled`; a default-on sub-system takes its switch inside its own
   config (`TimeSynchronization.Mode` or `Off`, folding
   `DisableTimeSynchronization` away — TimeSynchronization stays mounted by
   default, owner 2026-11-01; `Network.Reannounce` / `MDNS` likewise
   inside their structs, never a sibling `Disable…` bool); `Health` on
   when non-nil. Report the field mapping in the table.
9. **W5-api-11** — `OtaConfig.Harness` and `Network.WiFiCommissioning`
   leave `node.Config` for the `internal/nodeseam` seam the reference
   daemon reaches (or `fabrictest` where only tests use them);
   `BootID.RotateUniqueIDs` becomes the package call `bootid.EnableRotation()`
   (process-wide, documented as such).
10. **W5-api-12** — `contract`: unexport `InitialDataVersion` (a test
    override, if still needed, through an `internal/` seam); move the
    built-in materialisers' registration (`SetMeasurementMaterializer`)

11. **W5-api-14** — one `node.AheadRows()` returning the union of the root
    and device rows; remove `device.AheadRows` and its copy of the union
    helper; `surface.Policies.Extensions` doc points at it.
12. **W5-api-15** — remove `contract.DeviceTypeName`,
    `contract/devicetype_names_gen.go` and the label generation in

13. **W5-api-17** — rename `node.Config.Topology` → `Config.Snapshotter`,

16. **EventFiring** (W2-conc-02/03 follow-up, owner 2026-11-01) — remove

## Rules

- Read CLAUDE.md "matter.js is the gold standard" and "Token use". Cite
  the mirrored matter.js line in a `// Mirrors …` comment on every changed
  behaviour; a facade change cites the ADR principle it serves. Every
  behaviour item adds or flips a test; a pure API move keeps its tests
  compiling and green.
- No new dependency. API breaks only where an item says so, each with a
  migration line under Changed and a row in the migration guide. `make fmt`
  before each commit. No attribution lines. Generated files are
  regenerated (`go run ./script/devicegen`), never patched.
- Guards in the background with a summary log under
  `~/.cache/go-fabric-scratch/w5/` (`flock ~/.cache/go-fabric-scratch/guards.lock`,
  `export PATH=$HOME/go/bin:$PATH`): `make ci`, `make race` (per package;
  skip the root package under race and say so), `go test -count=1
  ./fabrictest/... ./script/devicegen/... ./examples/...`, `make apidiff-check`
  (it must list exactly the breaks above), `make cite-check`,
  `make reachability-check`, `make bench-smoke`, then `make chiptool-test`
  once at the end (the reference daemon changes: `node.New`, the pipe, the
  config fields). Regenerate a moved snapshot and commit it with the change.
  Read logs by grep, never cat. CodeQL runs on the PR.
- Report in the fixed shape: per item — commit, files, the test, the
  migration line; guard status with HEAD; differences from the brief;
  decisions taken (the field mapping of item 8, the alias names of
  W5-api-07); left out and why; open questions. Push the branch, open the
  PR with the report as body, do NOT enable auto-merge (the owner's
  reviewer verifies first).
