## Items (each a commit; the finding ID in the commit title)

1. **W2-conc-01 (medium)** — `bridge/subscribe.go` `reportSubscription` /
   `reportSubscriptionEvents`: on a send error re-mark the drained paths
   (`markDirty`) and restore the events (with item 2: the watermark) so
   the next tick retries the same data; the reap on the third failure
   stays. matter.js `packages/node/src/node/server/ServerSubscription.ts:569-582`.
   Parity test: a send that fails once reports the same paths on the next
   tick.
2. **W2-conc-02 (medium)** — `im/subscription/subscription.go:200-212,
   :303-304`: replace the copied `pendingEvents` with the lowest unreported
   event number plus an urgent flag and build the report from
   `EventLog.Query(…, minNumber)` at drain time; matter.js
   `ServerSubscription.ts:391-394, :541-542`. This also closes W2-conc-03
   (drain-time timestamps). Test: a burst of 10 000 events under a long
   floor holds no payload per subscription.
3. **W2-wire-02 (medium)** — `bridge/receive_dispatch.go:123-130
   rejectUnsupportedOpcode`: for `proto.Initiator` on a non-group session
   answer StatusResponse(InvalidAction) via `sendReply` and discharge the
   owed ack (the shape of `rejectGroupSession`); same for a StatusResponse
   that opens an exchange (`absorbStatusResponse`, `proto.Initiator &&
   !waited`). matter.js `InteractionMessenger.ts:415-419, :431-461`; chip
   `InteractionModelEngine.cpp:1095-1099, :1112-1115`. Flip
   `bridge/receive_test.go` `TestDispatch_IMResponseOpcodeIsUnsupported`
   and its sibling; add the byte case to the decode-error parity test.
4. **W2-wire-03 (medium)** — one helper in `im/` (`uintField(el, max)`:
   type `TypeUnsignedInt1..8` required, `el.Uint <= max`; ConstraintError
   for range as matter.js `TlvNumber.ts:151-155`, InvalidAction for type
   as chip `AttributePathIB.cpp:220-275` / `Parser.h:113-123`) used by
