# Gate 1 — architecture audit after phase 20a/20b (ADR 0025, ADR 0026)

Date 2026-10-20, on `main` at `ab4303fd` (v0.9.1 plus the typed cluster
layer of #198). Evidence: the inventory `notes/briefs/reads/read-gate1-inventory.md`
(Sonnet, a map: file:line per fact), the consumer experiment under
`notes/briefs/reports/G1-consumer/` (an Opus agent with no prior context,
allowed only `go doc` of `node`, `device`, `contract`, `fabrictest` and the
published guides, asked to write a bridge with a dimmable light and a
contact sensor plus its `fabrictest` test; its `NOTES.md` lists every
guess), and my reading of the lines the two name. One section per
principle; a finding is `G1-n` with the principle, the evidence, the fix
and its size. "Holds" means the evidence showed nothing against the
principle at this gate.

## ADR 0025 — the facade

**P1 The facade is the product.**
- **G1-1 A `device.NewDimmableLight` cannot be dimmed by a controller.**
  The kit's default for LevelControl is the generated `spec.Server` with
  its commands as unimplemented stubs (`device/device.go` `defaultServer`,
  `cluster/spec/server.go:179-183`, `:496-502`): MoveToLevel answers
  UNSUPPORTED_COMMAND. ADR 0018 (decision 2) foresaw the self-held
  servers as defaults "until they gain a self-held form"; `cluster/levelcontrol`
  has that form (`native.go`). Consumer note 1.5 and 4. Fix: the kit's
  default for every cluster with a self-held server is that server
  (devicegen's table, generated again from a list of self-held servers,
  not the three of before), with the typed hull's `Set`/`Handle` over it
  (G1-5). Size: devicegen table, the self-held servers' construction
  defaults, device tests, the daemon's `WithServer` calls shrink; one wave.
- **G1-2 Two request decoders, hand-written first.** `bridge/fields_reader.go:60-124`
  decodes LevelControl, DoorLock, ColorControl, FanControl, the mode
  clusters and the core commands by hand into `cluster/wire` types before
  asking the generated definition (`spec.DecodeRequest`, `:122`), so a
  generated server for one of those clusters — the kit's default today —
  gets the wrong payload type and its typed handler answers
  INVALID_COMMAND (`cluster/spec/typed.go` `HandlerOf`; consumer 1.5).
  ADR 0026 P3 (one source) as much as P1. Fix: the definition decodes
  first wherever one exists; the self-held servers accept the generated
  request types (their `MatterInvoke` switches, e.g.
  `cluster/energy/commoditytariff.go:1100` already do); the hand decoders
  and the `cluster/wire` request structs retire with the window. Size:
  `fields_reader.go` reordered (small), a type switch per self-held
  server (medium), tests; one wave with G1-1.
- **G1-3 Docs out of step with the typed layer.** `docs/getting-started/device.md`
  and `docs/guides/testing-in-process.md` show `light.OnOff().Set(on)`,
  which no longer compiles; the quickstart program is an include the
  page shows only when rendered; `node.Endpoint`'s doc still says "Brief
  P's device.Device … until that lands"; `fabrictest.Options.Logger` says
  nil discards while ~20 INFO lines reach stderr; `go doc ./device` is
  5 388 lines of generated tables and never names the `…def` import
  paths (consumer 1.1, 2, 4, 5). Fix: the docs half in BU (the host's
  view page), the `go doc` half in the generator (a package doc listing
  the typed packages by import path, the device-type tables moved to a
  generated `doc_gen.go` the page links) — small.

**P2 One shape.**
- **G1-4 Two ways for one thing, six times** (consumer §3): observing
  changes (`Device.OnChanged` and the typed `OnChanged`), acting on a
  command (`onoff.Config.Sink`, `Handle<Command>`, `OnWrite`), setting
  OnOff (`Set(bool)` on the self-held server, `Set(Patch)` on the hull),
  a sensor's state (`BooleanState().Set` or `WithMeasurement`), initial
  state (`WithInitial` or `Set` before start), and the clock
  (`device.Options.Clock` and `node.Config.Clock` kept equal by hand).
  Fix: the declaration of BU is the one form; the self-held servers
  implement `AttributeSetter`, `CommandRegistrar`, `EventEmitting` so
  `Set(Patch)`/`Handle<Command>`/`Emit<Event>` are the one shape over
  every server; `device.Options.Clock` defaults from the node at `Add`;
  `Device.OnChanged` stays as the untyped form of the same hook (one
  mechanism, two signatures) and says so. Size: BU.
- **G1-5 The typed hull over a self-held server can only Get and
  OnChanged** (BT report: onoff, Binding, EcosystemInformation,
  levelcontrol, light, thermo, cover, fan, pump return `ErrNotSettable`
  etc.), so a host writes `Underlying().(*onoff.Server).Set(true)`. Fix:
  the three interfaces on every self-held server (BU, named there).

**P3 No leaked types.** 39 declarations in `node`/`device` carry a lower
package's type (inventory §8).
- Owned aliases (18): fine by the principle.
- Seam accessors — `Node.Bridge()`, `Node.Store()`, `Node.Peers()`,
  `Node.Bindings()`, `RootClusters` — are the advanced seams by name
  and stay (P4), `Peers`/`Bindings` to be named in the seams page.
- **G1-6 Host-port types from `cluster/core` in `node.Config`:**
  `OTAProviderConfig` (`OTAImageSource`, `OTAConsent`, `OTAApplyPolicy`,
  `OTAUpdateStatus…`), `OtaConfig.Applier` (`OtaApplier`), `WiFi.Reporter`
  (`WiFiReporter`), `CommissionerControlConfig` (`CommissioningApprover`,
  `ReverseCommissioner`), `Config.CapabilityMinima`/`GeneralDiagnosticsFeatures`,
  `WindowSnapshot` (`wire.WindowStatusSnapshot`), `Config.DeviceTypeValidation`
  (`endpoint.DeviceTypeValidationMode`), `Attestation.Chain`
  (`attestation.Chain`), `Client` (`discovery.Names`), `Aggregator.Remove`
  and `EndpointPersistence` (`endpoint.SourceKey` where `device.SourceKey`
  is the facade's name), `node.Endpoint` and `Device.Spec()` (`endpoint.Spec`),
  `Store` (`endpoint.Store`, `store.Store`, `sql.DB`). Fix: an owned
  alias or type per port in `node` (the host implements `node.OTAImageSource`
  …), `device.SourceKey` in the signatures, `node.DeviceTypeValidationMode`;
  `Spec()`/`node.Endpoint` stay the documented bridge to the Matter-near
  level. Whether the host ports belong in `contract/` (stdlib-only; they
  reference `cluster/core` types today) is a question for gate 2. Size:
  small, mechanical; apidiff-neutral (aliases).

**P4 Seams are not the facade.** Holds: the seams page exists (BS); add
`Peers`, `Bindings`, the OTA download directory and the DCL file store
to it (G1-6, G1-16).

**P5 Vocabulary.** No exported identifier named Behavior, Agent,
Transaction, Backing or Hull (inventory §8). **G1-7** Two packages named
`onoff` (`cluster/onoff`, `cluster/spec/onoff`) meet in every host file
as `onoff` and `onoffdef`; the alias convention is undocumented
(consumer 2). Fix: the typed packages' doc and the host's-view page name
the convention; no rename (BU).

**P6 Semantics from matter.js.** Holds; the one divergence of the wave has
its entry (`BD-Matter-TypedServer-WriteVeto`).

**P7 Errors are values.**
- **G1-8 The dispatcher's text fallback.** `endpoint/dispatcher.go:831-890`
  maps an error to a status by `strings.Contains` after the typed check;
  `cluster/core/access_control.go:708-783`, `:896-908` reach it by
  wording ("resource exhausted:"). Fix: typed status errors there, the
  fallback removed (a plain error is FAILURE). Small.
- **G1-9 Error prefixes.** 23 of 70 package directories prefix their
  errors with something other than the package name (`cluster/core`:
  `matter:` ×38, none ×10; `controller/attestation`, `controller/commissioner`,
  `controller/dcl`, `store`: unprefixed) (inventory §5a). Fix: a sweep,
  prefix = package name; mechanical.

**P8 Callbacks inline with an async option.**
- **G1-10 `OnChanged` carries no origin.** It fires for the host's own
  `Set` too, and `device.md` files it under "controller to device"
  (consumer 1.4, 4). Fix in BU: the typed `OnChanged` reports the origin
  (controller write, command, host set) or the page says it fires for
  both and `OnWrite`/`Handle` are the controller-only hooks; the `…Async`
  variant of ADR 0025 is BU's.

**P9 Every break announced.** apidiff is BV; `Fabrics()` is deprecated
with its release; the accessor break is announced for `v0.10.0`. Holds
until BV.

**P10 The same bar inside.** See ADR 0026 P5–P9 below; the typed layer's
reflection conversion (`cluster/spec/typed.go` `convert`, `stateOf`: a
stored value of an unexpected type leaves the field zero) is accepted
for this gate and re-judged at gate 2 with the self-held servers under
the hull.

**P11 Provable without hardware.** The consumer's `fabrictest` test
commissioned the bridge and read both devices (consumer §5). **G1-11**
It needed `im.Concrete*Path` with four `Has*` flags by hand and found no
production API for a device's endpoint number (consumer 2). Fix: the
typed controller-side reads of BV (`site.Controller().Read(dev).<Cluster>()`)
and `Device.EndpointNumber()` after `Add` (BU). 

**P12 Few dependencies.** Holds (six direct, `x/tools` for the
reachability guard; the `tool` directive of BV is the next decision).

## ADR 0026 — the architecture

**P1 Layers and direction.** `make archcheck` passes with five
exceptions. **G1-12** `binding → controller/{exchange,handshake,interaction,peer}`
(and `node → controller/*` for the client stack): the four packages are
the role-neutral client machinery (CASE initiator, exchanges, the
client interaction, the peer set) under the controller's name. Fix:
move them to a role-neutral tree (`client/exchange`, `client/handshake`,
`client/interaction`, `client/peer`) with type aliases under the old
paths for the deprecation window; the exceptions go. Size: large but
mechanical (imports in ~40 packages, docs, the register's `go` refs);
an Opus wave of its own. `cluster/spec` under `cluster/` is a model
package in a server directory: archcheck treats it as model; a move to
`spec/` would rename 119 public packages for no host gain — recorded
in ADR 0026, not moved (ADR change).

**P2 One composition root per role.** Holds (`bridge`/`node`,
`controller/*`); `node.New` building the advertiser and the store is the
root's job.

**P3 Generated code from one source.** **G1-2** above (the hand decoders
beside the generated definitions). Otherwise holds: every generated
package has its snapshot test.

**P4 Time and randomness.** Two raw `time.Now` sites remain, both
`SetReadDeadline` on a kernel socket (`mdns/subtype_responder.go:358`,
`:384`) — a kernel deadline needs wall time; holds with a comment. **G1-13**
`clock.System{}` constructed directly in `fabrictest/site.go:200` and
`transport/btp/session*.go`: inject. Randomness: 33 files read
`crypto/rand` directly, a seam exists where a test needs determinism
(SPAKE2, MRP, groups, the controller's jitter); the principle's "one
function per package, replaceable in tests" is stricter than the module
needs — **ADR change**: `crypto/rand` directly is the rule, a declared
seam only where a test needs determinism.

**P5 Every goroutine has an owner.** 79 goroutine sites (inventory §2);
**G1-14** owners that do not wait: `secure/operational.Manager.StartReaper`
(`manager.go:1183`, no handle, no Stop), `controller/exchange.Manager.dispatch`
(`manager.go:757`, no WaitGroup; `Close` closes sessions only),
`transport/tcp.Conn.serve` (`conn.go:194`, no wait), `bridge.triggerSessionReannounce`
(`securechannel.go:1279`), `cluster/core` Identify countdown (`identify.go:264`),
the lock timers' `go` inside `AfterFunc` (`users.go:362`, `doorlock_server.go:970`),
`node/ota.go:104` `restartedWhenIdle`, `diagnostic_logs.go:547`,
`bdx_responder.go:108`. **G1-15 The restart flake** "[fe80::1]:5540 is in
use" (`TestClientNodeParity/decommissions`, `TestNodeLifecycleSeededPairParity`;
CI run 39472173674): shutdown, listener close and socket release are
synchronous (`fabrictest/controller.go:222-260`, `transport/udp/listener.go:306`,
`fabrictest/net.go:134-146`, `:229-275`), so a second socket of the same
host index is opened outside `c.listener`, or `start` runs without a
`shutdown` — to be reproduced with `go test -race -count=20`. Fix: a
WaitGroup or done channel per owner above, `Stop` waits; the flake's
cause read and fixed. Medium; part of the fix wave.

**P6 Locks few, named, ordered.** 199 mutexes, 149 without a comment
naming what they protect; 119 calls under a held lock to a function
field, an interface or I/O (inventory §3c). **G1-16** The ones that
call host code under a lock: `cluster/core/messages.go:255`, `:277`
(`presenter.PresentMessage`/`CancelMessage` under `m.mu`),
`cluster/cover/windowcovering_server.go:647-649` (`mover.Stop`/`GoTo`
under `s.op`), `cluster/energy/devicemanagement.go:663-809` (`manager.*`
under `s.mu`), `cluster/appliance/microwave.go:320-337` (`oven.*`),
`cluster/measurement/soil.go:115` (`src.MatterFloatValue`), `bdx/sink.go:55-107`
(file I/O under `s.mu`). Fix: each read, the host call moved outside
the lock (snapshot under lock, call after); a one-line comment on every
mutex; medium, mechanical for the comments.

**P7 Persistence is one seam.** **G1-17** File access outside the seam
(inventory §7): `bridge/subscribe_dispatch.go:425` writes
`/tmp/subscribe-init-sub…bin` behind an env switch — remove; the OTA
directories (`node/ota.go`, `cluster/core/ota_requestor_query.go`), the
DCL file store (`controller/dcl/store.go`), the CA key file
(`controller/ca/keyfile`) and the attestation files are file-based
by nature — **ADR change**: P7 names them as the file seams, each
behind one path a host configures.

**P8 Errors one style.** G1-8, G1-9 above. `cluster/*` importing `im` for
the status vocabulary (33 identifiers, 75 files; inventory §1a): the IM
status is the wire's own vocabulary and `im` is in the layer below the
servers — holds; the servers spell a status, the dispatcher maps it
once (after G1-8).

**P9 Observability.** **G1-18** 10 event names not in dotted lower case
(`im/subscription/manager.go:340`, `persistence.go:121`,
`endpoint/assembler.go:378`, `:395`, `cluster/core/general_diagnostics.go:364`,
the `tlv` package-level `slog.Warn` at `encode.go:239`, `:323`), 44
inline `slog.Default()` calls in 15 files (`cluster/thermo/thermostat_server.go`
×9, …), one print in `ble/bluez/cmd`. Fix: a sweep; mechanical.

**P10 Tests are architecture.** 223 packages pass in 364 s; the seven
flaky tests have their wait named (inventory §9c): the reaper test polls
wall time, `TestDiagLogsBDX_Transfer` runs on real time, the rest on
`fabrictest` waits under load. **G1-19** Fix with G1-14/G1-15: the two
wall-clock tests onto the fake clock; `controller/client` (109 s) and
`node` (73 s) are the runtime to watch at gate 2.

**P11 Structural rules are guards.** archcheck holds P1; apidiff (BV)
holds 0025 P9; P5/P6/P8/P9 have no guard — a lint rule for inline
`slog.Default()` and for `errors.New` without the package prefix is
cheap (`golangci-lint` `forbidigo`/a custom analyzer); gate 2 decides.

**P12 Role-neutral shared packages.** G1-12. `controller/client → device`,
`endpoint` (inventory §1b): to read in the same wave; if it is the
client's view of device types, `schema` is the right source.
