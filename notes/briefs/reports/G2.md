Date 2026-10-22, on `main` c9e7c473 (#213 BU-b merged; #214 pending).
Evidence: the inventory `notes/briefs/reads/read-gate2-inventory.md`
(§1–§12, Sonnet, a map) and the context-free consumer
`notes/briefs/reports/G2-consumer/` (Opus; `NOTES.md` 21 findings; the

## ADR 0025 — the facade

**P1 The facade is the product.**
- **G2-1 LevelControl reports no change** (consumer 1, 2). `LevelControl().OnChanged`
  never fires for a host `Set` or a controller's MoveToLevel, and a host
  `Set` of CurrentLevel never reaches a subscriber (a Read shows it). The
  server reports CurrentLevel itself (`cluster/levelcontrol/transitions.go:221`)
  but notifies only on the transition path (`:94`, `:108`); the immediate
  command path and `SetAttributes` → `heldLevel.setLevel` (`held.go:122`,
  `typed.go:39`) store silently; `OnAttributeChange` follows the source
  only when it is a `ChangeNotifier` (`:183-215`). For a bridge this is
  "the level never updates in Apple Home". **BY-1.**
- **G2-2 A controller's setpoint write is stored and not reported to the
  host** (consumer 3). `thermostat_server.go:712-745` notifies the coupled
  attributes only; the dispatcher reports the written one to the wire but
  the host's `OnChanged` sees nothing, against `docs/guides/host-view.md:57-61`.
  BU-b's `CheckOrigins` asserted the port, not the listener. **BY-1**
  (with the audit extended to the listener, every self-held server).
- **G2-3 Docs a consumer cannot read.** The quickstart programs are mkdocs
  snippets (`--8<--`, `device.md:34`, `controller.md:34`), invisible on
  GitHub and to `go doc`; the `fabrictest` package example imports
  `onoff` where every page says `onoffdef` (consumer 20); the node
  godoc cites a `wiring.go` that no longer exists (inventory §11c);
  the migration guide says `v0.9.2` (line 135) and cites stale
  `fabrictest` lines (155) (§12a). **BY-2** (docs: the programs inline
  or linked by absolute URL, the citations regenerated — and a test
  that every `*Source: file:line*` and `file.go:NN` in `docs/` resolves).

**P2 One shape.**
- **G2-4 Construction and runtime forms side by side** (consumer 12):
  `Declare.Handle<Cmd>`/`OnWrite` and `Server.Handle<Cmd>(fn) error`/
  `OnWrite(fn) error`. Both are right — the declaration is construction,
  the setter a change at run time — but nothing says so. **BY-2**: the
  setters' doc and `device.md` state the rule in one sentence; no API
  change.
- **G2-5 One hook, three signatures** (consumer 15): the typed
  `Server.OnChangedAsync` returns `(unsubscribe, error)` (`spec.ErrNoQueue`),
  the typed `OnChanged` and `Device.OnChangedAsync` return no error.
  **BY-2**: one signature — `OnChangedAsync` never errors (a device
  without a queue — not added — delivers nothing, as documented in
  BD-Matter-AsyncCallbacks-OnlyWhileAdded); `spec.ErrNoQueue` goes.
- **G2-6 Two ways for the NodeLabel and the subscription** (consumer 13,
  14): `device.Options.NodeLabel` beside `Device.Rename` (the node
  persists the label since BU-a, so the option is a leftover) — **BY-2**:
  remove `Options.NodeLabel`, migration-guide line. `CommissionOptions.AutoSubscribe`
  beside `Node.Subscribe` is two levels of one thing (a default and a
  custom subscription); **BY-2** docs: when to use which, and that
  `KeepSubscriptions` is the rule for both together.

**P3 No leaked types.** Inventory §8a: 71 declarations carry a lower
package's type without an owned alias — `fabrictest` 27, `controller/client`
15, `node` 14, `controller/commissioner` 10, `controller/ca` 2, `controller/dcl`
2, `device` 1; `contract` and `controller/attestation` 0.
- `node`'s 14 are the documented seams (`Bridge`, `Store`, `Groups`,
  `Peers`, `Bindings`, `RootClusters`, `CommissionerControl`,
  `OTAProvider`, `EndpointPersistence`) plus three in `Config`
  (`clock.Clock`, `groups.Manager`, `mdns.Advertiser`) and `node.Endpoint`
  → `endpoint.Spec`. `clock.Clock` is foundation vocabulary and stays;
  **G2-7 BY-2**: `node.Groups`/`node.Advertiser` aliases for the two
  `Config` fields; `device.Spec()`/`node.Endpoint`'s `endpoint.Spec` is
  the seam (holds).
- **G2-8 The controller role has no owned surface** (consumer 5, 6, 11,
  17; §8a): `controller/client`'s `Read`/`Subscribe`/`Write`/`Invoke`
  take and return `interaction.*` and `im.*` types; `fabrictest`'s wire
  helpers the same; `Cluster.Decoded` returns `any` with widened integers
  (a uint8 as `uint64`), documented nowhere; no facade value exists for
  writing a scalar (the consumer wrote its own `tlv` encoder). Fix: the
  controller side gets the typed counterpart of the device side —
  generated per-cluster client reads over the `State` types
  (`site.Controller().Read(dev).<Cluster>()` of concept v6, Teil A),
  `spec.Value[T]` scalars as `Encodable`, and `client.ReadRequest`/
  `SubscribeRequest`/`Report`/`AttributeData` as owned aliases in
  `controller/client` and `fabrictest` with their fields documented.
  **BV** (the brief's typed controller reads), with the aliases first.
- `controller/commissioner`'s 10 and `fabrictest.Controller`'s seams
  (`Exchanges`, `Names`, `Peers`, `Subscriptions`): seams of the role,
  to be listed as such in `docs/guides/advanced-seams.md` — **BY-2** docs.

**P4 Advanced seams are not the facade.** Holds; `WithServer` has no
non-test use (§10d), the seams are named. The reference bridge still
imports `cluster/core` (8 files), `controller/dcl`, `bdx`, `bdx/otaimage`,
`cluster/energy`, `clock` (§11b/c): six of the `cluster/core` names have
`node` aliases the example does not use (**BY-2**: use them); `OTAImage`,
the OTA consent constants, `Actions*`, `EcosystemDirectory`, `FixedLabel*`,
`PowerSourceConfiguration`, the DCL client, the OTA image builder and
EVSE's `HostServer` have no route — **G2-9**: routes for the node
features (`node.OTAImage`, consent constants, `node.Actions*`,
`EcosystemDirectory`, FixedLabel as `fixedlabeldef.Declare`, the DCL
lookup and the image builder as `node/ota` helpers or documented seams)
— **BV**, after the tag; the decision per name in BV's brief.

**P5 Vocabulary.** No `Behavior`/`Agent`/`Transaction`/`Backing`/`Hull`
identifier (§8c). `interaction.AttributeData.Value.El.Uint` exposes the
TLV element (consumer 5) — part of G2-8. `StateSource.IsLocked()
(locked, observed bool)` and `spec.Nullable`'s zero value are undocumented
(consumer 7, 10) — **BY-2** doc comments. Timed commands: `schema.IsTimedInvoke`
exists; the generated `Cmd*` constants' comment should carry `timed`
(**BY-2**, clustergen).

**P6 Semantics from matter.js.** Holds after BU-b's audit, with G2-1/2
as the exceptions (both are reporting gaps, not semantics).

**P7 Errors are values.** `classifyError` maps by type only (§5c).
- **G2-10** Plain errors whose wording matched the removed fallback
  (`read-only`, `unknown command`: `icd_management.go:87`,
  `network_commissioning.go:230`, `network_commissioning_wifi.go:245`, …
  §5c) now answer FAILURE where UNSUPPORTED_WRITE / UNSUPPORTED_COMMAND
  is the status — **BY-2**: typed, with a test per site; the stale
  comment `group_key_management.go:746` goes.
- **G2-11** `Site.Eventually` on `context.Background()` waits forever
  (consumer 11; the docs example `testing-in-process.md:161` shows it).
  **BY-2**: `Eventually` takes the site's deadline when the context has
  none (the wall clock of `Options.Wall`, a documented default), and the
  example sets one.

**P8 Callbacks inline, Async option.** Holds (BU-a, by_design). G2-5 is
the signature.

**P9 Every break announced.** The guide covers all 900 removed symbols
(§12b) except the 20 per-type `OnMatterAttributesChanged` methods (one
row: "`OnMatterAttributesChanged` → `OnAttributeChange(func(contract.Change))`
on every server" — **BY-2**); the `v0.9.2` sentence and the stale Source
lines are G2-3. `apidiff` is **BV**.

**P10 The same bar inside.**
- **G2-12** The hull still converts `State` from the stored values by
  reflection (`spec.StateOf`, BT) and `PatchValues` keeps a reflection
  fallback for non-generated structs (BU-b review). **BY-2**: the
  generator writes `State.fromValues` per field as it writes
  `Patch.AttributeValues`; the fallback goes with it (a test struct gets
  its own methods).
- `device.Spec.Type uint16` — a named `schema.DeviceTypeID` from the
  schema generator, **BY-2** (small; the migration guide gets the line).

**P11 Provable without hardware.** Holds: the consumer's bridge and
controller ran on `fabrictest` in 5 s. The flakes are under ADR 0026 P10.

**P12 Few dependencies, one binary.** Holds (five direct dependencies,
`CGO_ENABLED=0`).

## ADR 0026 — the architecture

**P1 Layers and direction.** `make archcheck` passes with **no**
exception (§1; BX4, BZ). `controller/client → device, endpoint`
(`endpoint.go:78-79` `device.Type`/`Lookup`, `conformance.go:66-177`
`DeviceTypeTree`, `ClusterShape`, `DeviceTypeViolation`) is a downward
edge in the layer order and stays; P12 below says what it means.

**P2 One composition root per role.** Holds.

**P3 Generated code has one source.** G2-12; otherwise holds (clustergen
writes `Declare`, `AttributeValues`; devicegen the device files; the
generated tests check both).

**P4 Time and randomness injected.** Holds (§4: the two `SetReadDeadline`
sites with their comment; `crypto/rand` direct per the gate-1 amendment).

**P5 Every goroutine has an owner.** Holds after BX2 (§2); the per-device
Async queue is owned and drained (BU-a). Open: a slow Async callback
holds `Node.Stop` for its length — documented, not bounded; **gate 3**
decides a bound.

**P6 Locks.** 214 mutex declarations, 175 commented (§3a; the 39 without
are BX2's own structures and the skipped security files — **BY-2** sweep
with the BX3 script, security files by the owner). §3c: 122 flagged
calls; the ones that leave the module under a lock: **G2-13**
`bridge/group_messaging.go:237` (`LeaveGroup` on the network under
`groupNetMu`), `client/interaction/sustained.go:278` (`VerifyReachability`
under `st.mu`), `client/peer/set.go:205` (`ctx.Fabrics` under `s.mu`),
`bdx/sink.go` (file I/O under `s.io`, the serialiser BX2 chose — holds).
**BY-2**: snapshot, release, call; the funcvalue/funcfield rows read once
by the implementing agent, each judged in the report.

**P7 Persistence is one seam.** §7: outside the four seams of the gate-1
amendment, `cluster/core/ota_requestor_query.go` (`os.Stat/Remove/Open`
on the downloaded image) and `controller/dcl/snapshot/fetch.go`
(`os.RemoveAll/MkdirAll/WriteFile`) touch files directly — **G2-14**,
**phase 21** (the persistence ports: the OTA requestor's download goes
through `bdx`'s sink, the DCL snapshot through `dcl.FileStore`); the ADR's
seam list gets both names until then (**ADR**).

**P8 Errors with one style.** Prefixes hold (§5a: 587 literals, one per
package). G2-10. The gate-1 question whether a status type moves below
the servers: `cluster/* → im` is a downward edge in the layer order
(`im` is model and protocol), 38 files spell statuses through
`im.UnsupportedCommandf`/`spec.Errorf(im.Status…)`; **holds — closed**
(**ADR**: P8's last sentence becomes the answer).

**P9 Observability.** Holds: 0 of 571 event names off the rule (§6a), no
inline `slog.Default()` (§6b), the three security servers injected (#205).

**P10 Tests are part of the architecture.** The flakes (§9b/c):
- **G2-15** `TestLiveSustainedSurvivesRestart` failed in the inventory
  run (`live_test.go:357`: the subscription id after the restart is a
  new id, the test wants the old one) — a wrong assumption or a real
  regression of sustained-subscription resumption after BX2's
  ownership change; **BY-2** reads which.
- **G2-16** the commissioner's `errWon` surfacing (`connection.go:305`,
  CI once), `TestDelayReportDataParity` (fake time advanced without
  waiting for the sender, CI once), `TestRegistryDecommission`,
  `TestDiagLogsBDX_Transfer` (real-time channels, a negative 50 ms wait),
  `TestNetworkLossAndDelay`, `TestOtaParityMatterJS`: **BY-2** — one
  sweep, each reproduced with `-race -count=20` under `stress`-like load,
  the cause fixed or the test's wait made deterministic; a test that is
  sound and only slow is listed as such.
- `controller/client` at 162 s and `node` at 81 s per run (§9b): **gate 3**
  (split or parallelise; no change before the tag).

**P11 A structural rule is a guard.** archcheck, the generated tests,
`TestCertifiabilityDocument`, the register ratchets: hold. Missing
guards named at gate 1 — a lint rule for `slog.Default()` inline and for
error prefixes — **BY-2** (`forbidigo` for `slog.Default().`; the prefix
rule as a small analyzer test over `errors.New`/`fmt.Errorf` literals);
G2-3's docs-citation test is the third.

**P12 Role-neutral shared packages.** The client machinery is `client/*`
(BX4). `controller/client → device, endpoint` is the controller reading
device types and validating a peer's composition with the server-side
validator: the validator is role-neutral by content and sits in
`endpoint` by history. **M5** (the controller remainder): move
`DeviceTypeTree`/`ClusterShape`/validation to a role-neutral package
under the model layer (`schema` or `conformance`) when M5 touches the
client's composition reading; until then the edge is downward and
documented here (**ADR**: P12 names it).
