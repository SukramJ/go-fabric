## 1 Error prefixes (G1-9; ADR 0026 P8)

Rule: the message of an `errors.New`/`fmt.Errorf` sentinel starts with
the package name and a colon (`bridge: …`, `core: …`, `store: …`). The
23 directories of inventory §5a: replace `matter:` with the package name
in `cluster/core` and `cluster/wire`; add the prefix where there is none
(`store`, `controller/attestation`, `controller/commissioner`,
`controller/dcl`, `node`, `im`, `mdns`, `bdx/otaimage`, `internal/chipdm`,
`secure/attestation`, `secure/sigma`, `secure/spake2`, `transport/btp`);
sub-package prefixes (`receive:`, `reply:`, `privacy:`, `securechannel:`
in bridge; `microwaveovencontrol:`, `closurecontrol:`, `windowcovering:`,
`colorcontrol:`, `doorlock:`, `thermostat:`, `temperaturecontrol:`) become
the package name. **A message a test asserts on** (grep the string in
`*_test.go`; also `internal/chiptool` expectations and
`docs/`) is changed together with its test; a message that is part of a
wire payload or a status text a chip-tool case reads (`DebugText`) is
left as it is and listed. The script prints every change as a diff line.

- The 10 event names of inventory §6a become dotted lower case

  `slog.Warn` calls get names `tlv.utf8_truncated`, `tlv.utf8_trimmed`

  listed in the report. The one print in `ble/bluez/cmd/...` becomes a
  log line or stays if it is the CLI's own output (say which).
