## BV-a — the controller's typed surface and apidiff

### 1 Values a developer can write and read (G2-8; ADR 0025 P5)

- `spec.Value[T]` (or the name the package's style gives): an `Encodable`
  for every scalar the definitions use — the integer widths, bool,
  float, string, octet string, `Nullable[T]` — so `fabrictest.Write` and
  `client.Node.Write` take `spec.Uint8(20)`, `spec.Int16(2250)`,
  `spec.Null[uint16]()` without `tlv`. Read matter.js's client-side
  value handling (`packages/protocol/src/action/client/*`, the
  `AttributeData`/`Report` decode path) and cite how a read value is
  typed there.
- Generated per-cluster client reads over the `State` types: from a
  `Report`/`AttributeData` set, `<cluster>def.StateFrom(report)` (or a
  method on a client-side `Reader`) fills a `State` with the attributes
  present and reports which were absent; `fabrictest.Pair.Read(dev).<Cluster>()`
  (concept v6: `site.Controller().Read(dev).<Cluster>()`) and
  `client.Node.ReadTyped[T]`/`Cluster.State()` on the controller side —
  one generated path, no reflection (ADR 0026 P3; a `StateReader`-style
  interface as BY-2 wrote). `Cluster.Decoded` stays as the untyped form
  with its widening documented, or goes if the typed form covers every
  use (say which; migration-guide line either way).
- Tests: the consumer's controller program (`G2-consumer/controller_test.go.txt`)
  rewritten on the typed reads is `controller/client/typed_reads_consumer_test.go`;
  a `fabrictest` test per generated package in the spectest pattern
  (read → State equals the device's `Get()`).

### 2 Owned surface of the role (G2-8; ADR 0025 P3)

- `controller/client`: owned aliases (or own types where the shape is
  the client's) for `ReadRequest`, `SubscribeRequest`, `WriteRequest`,
  `Report`, `AttributeData`, `EventData`, `Subscription`, `Result`,
  `InvokeOptions`, `WriteOptions`, `WriteStatuses`, `PeerAddress`,
  `Device` (discovery), `SupportedTransports`, `Timing` — the inventory
  §8a list; every field a host sets is documented on the alias's doc
  comment (`Attributes`, `Updated`, `KeepSubscriptions`, how a
  `Subscription` is closed). `fabrictest` the same for its 27 (`Read`,
  `ReadWith`, `Write`, `Invoke`, `Subscribe`, `Events`, `Connect`,
  `Exchange`, `Pair`, `Topology`, `Options.Clock`/`Wall`); the seams
  (`Controller.Exchanges/Names/Peers/Subscriptions`, `Device.Bridge/Store/Advertiser/Endpoints`)
  are named in `advanced-seams.md` and stay.
- `docs/getting-started/controller.md`: the production controller's
  nine-package build (consumer 21) becomes a `controller.New(controller.Config)`
  composition root in `controller/` (ADR 0026 P2: one root per role) if
  the read of `commissioner`, `ca`, `dcl`, `client` shows it is a
  wiring, not a design — say in the report what it took; if it is a
  design, the page documents the wiring and the brief of M5 carries it.

### 3 apidiff (ADR 0025 P9; concept decision 0.2)

- `golang.org/x/exp/cmd/apidiff` as a tool dependency (`tool` directive
  in `go.mod`, Go ≥ 1.24; a sixth dependency is a decision — this one
  is the owner's of 2026-10-20), `make apidiff` compares the public
  packages against the last tag (`git describe --tags --abbrev=0`) and
  prints the incompatible changes; `make apidiff-check` fails when an
  incompatible change has no CHANGELOG line under `[Unreleased]`
  naming the symbol (the rule: a break is announced before it ships).
  CI job. The README's "How a consumer learns about a break" names the
  guard; the suspended window paragraph stays.
