# Gate 2 — architecture audit of the whole facade before v0.10.0 (ADR 0025 + ADR 0026)

Runs after BU-b (#213) merges. Owner decisions (2026-10-20): gate 2 covers
the whole facade **including `controller/`**; its findings are fixed in
their own wave before the v0.10.0 tag; loom's full migration follows the
tag. Template: `notes/briefs/2026-10-20-G1-gate1-audit.md` and report
`notes/briefs/reports/G1.md`.

## Three parts, one report (`notes/briefs/reports/G2.md`)

1. **Inventory (Sonnet, `notes/briefs/reads/read-gate2-inventory.md`)** —
   a map with `file:line`, no judgement, the same sections as gate 1
   (§1 import graph incl. `client/*` and `controller/*`; §2 goroutines
   and timers; §3 locks; §4 time/randomness; §5 errors; §6 logging;
   §7 persistence; §8 facade surface for `node`, `device`, `contract`,
   `fabrictest`, **`controller/client`, `controller/commissioner`,
   `controller/ca`, `controller/dcl`, `controller/attestation`**:
   exported identifiers whose types come from a lower package without
   an alias, matter.js-internal vocabulary; §9 tests and flakes) plus:
   - §10 the declaration: every `<cluster>def.Declare` field with its
     port type; every self-held server with/without a declared port;
     every kit default and its fallback; `WithServer`'s remaining uses.
   - §11 the reference bridge's and `examples/host-view`'s imports per
     file (BU-b's exception list) with the node route that exists.
   - §12 the migration guide against `go doc`: every symbol the guide
     names exists; every removed symbol since v0.9.1 has its line.
2. **The consumer (Opus, fresh context, read-only worktree at main)** —
   receives `go doc -all ./node ./device ./contract ./fabrictest
   ./controller/client`, `docs/getting-started/*.md`, `docs/guides/*.md`
   and two tasks: (a) a bridge for a dimmable light, a contact sensor, a
   thermostat with a host-side setpoint source and a door lock with an
   actuator, as a Go program on the declaration, with a `fabrictest`
   test that commissions it, reads all four, moves the level, writes the
   setpoint and locks the lock; (b) a controller program over
   `controller/client` that commissions that bridge over `fabrictest`,
   subscribes to the light and reads the thermostat with the typed
   reads. Notes on every guess, missing name and second way; kept under
   `notes/briefs/reports/G2-consumer/`.
3. **The judgement (Fable)** — one section per principle of ADR 0025
   (12) and ADR 0026 (12), each with evidence, finding or "holds", fix
   and wave. Candidates going in (from gate 1's deferred list and the
   waves since):
   - the two CI flakes: `controller/commissioner` errWon surfacing
     (`connection.go:305`; hypothesis: two successful PASE attempts to
     one fabrictest address, the loser's `HandlePeerLoss` hits the
     winner) and `TestDelayReportDataParity` (fake clock advanced
     without waiting for the sender);
   - EVSE's delegate model (ports under the state lock) — the last
     exception of BD-Matter-HostPort-OutsideTheSetterLock;
   - `controller/client → device, endpoint` (BX4 §3: `Endpoint.Device()`
     returns `*device.Type`; `Conformance` runs the server-side
     validator) — role-neutral or a schema-derived client view;
   - `device.Spec.Type uint16` → a named `schema.DeviceTypeID` (generator);
   - aliases vs interfaces for `SessionManager`/`SubscriptionManager`;
     `Get()` zero on a type mismatch; `node`'s race runtime; lint rules
     for `slog.Default` and error prefixes (forbidigo / analyzer);
   - the reference bridge's remaining imports (BU-b §11): OTA/bdx, DCL,
     attestation, WiFi, Actions, EcosystemDirectory, FixedLabel,
     PowerSourceConfiguration, TCP — route, seam or declaration each;
   - PowerSource EndpointList (host today; a declaration field or a
     topology-derived default), per-device FixedLabel declaration,
     ContentControl/ContentAppObserver;
   - the command-origin race (a host `Set` during a handler tagged
     with the command's origin) — by_design or a fix;
   - `AppBasic`/`WakeOnLan`'s typed state beside their store
     (BX1 Left out);
   - the `Async` queue's drain on `Node.Stop` under a slow callback
     (bounded? ADR 0026 P5);
   - `controller/`'s own facade: the commissioner's and client's config
     shapes against ADR 0025 P2/P3/P5 (one shape, no leaked types,
     spec vocabulary), the `fabrictest` controller's typed reads (BV).
4. **The fix wave (BY)** — from the findings the owner accepts (wizard:
   now / after v0.10.0 / ADR change); Opus, or two on disjoint paths;
   then CHANGELOG, roadmap, README for the tag; `v0.10.0` after it
   (BT + BU + the gate-1 and gate-2 fixes; BV's `apidiff` guard comes
   after the tag as planned).
